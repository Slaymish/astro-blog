Privacy policy

Hermes Agent — last updated 21 October 2026

Hermes Agent is a private automation agent with exactly one user: its owner, Hamish Burke. It is not offered to the public, has no sign-up, and is not installed on anyone else's machine. This policy explains what it can access, where that data lives, who can see it, and how access is withdrawn.

Who operates it

Hamish Burke, Wellington, New Zealand. Contact: hamish@burke.kiwi. There is no company, no other account holder, and no other user.

What it can access, and why

Access is granted by the owner, to himself, through Google's OAuth consent screen. Only the scopes he approves are granted, and each exists to do a task he asked for:

Google dataWhy
Gmail (read, send, modify)Find and summarise email he asks about; draft replies; send messages he has approved.
CalendarRead his schedule to plan his day; create or move events he asks for.
Drive, Docs, SheetsRead and edit files he points it at, and create documents on his instruction.
ContactsResolve who an email is from or to, so it addresses the right person.
TasksAdd, complete and list his own task items.

It does not access anything outside these scopes, and does not read other people's accounts.

Where the data lives

On the owner's own laptop, in local files that only he can read. There is no Hermes server, no hosted backend and no cloud database holding this data. Nothing is sold, rented, or shared with advertisers or data brokers, and nothing is used to train machine-learning models.

Third parties

To produce answers, the agent sends the specific text needed for a task to a large-language-model provider under the owner's own account, in the same way he would send it to a search engine. It uses no analytics or tracking services, and no advertiser SDKs. When a task requires another service (for example a price lookup), only the minimum needed for that task is sent.

Google API Services User Data Policy

Hermes Agent's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is not used for advertising, is not sold, is not used to develop, improve or train generalised or non-personalised AI or machine-learning models, and is not read by humans except where the owner reads his own data or where required for security or legal reasons.

Retention and deletion

Data stays until the owner deletes it. Local records can be removed at any time by deleting the files on his machine, and the OAuth grant can be revoked at any time at myaccount.google.com/permissions, which immediately ends the agent's access. Revoking access does not require asking anyone.

Security

OAuth tokens are stored locally with file permissions restricted to the owner's user account. The machine is protected by its own login and disk encryption. No credentials are shared with, or stored by, any third party.

Changes

If this policy changes, the date at the top changes with it. Because there is one user, there is nobody else to notify.
