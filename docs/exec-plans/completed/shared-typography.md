# Consolidate the site's typography

This living ExecPlan follows `PLANS.md` in the repository root.

## Purpose / Big Picture

Readers should recognise the same hierarchy across work, writing, reading and informational pages. Replace individually chosen font sizes with six shared roles, while retaining the distinctive homepage name. Dates and tags use the main font so they do not introduce another visual style.

## Plan of Work

First define small text at 0.875rem, body text from 1rem to 1.125rem, introductions from 1.125rem to 1.5rem, card titles from 1.5rem to 2rem, section headings from 2rem to 3rem and page headings from 2.75rem to 4rem in `src/styles/tokens.css`. Preserve existing token names as aliases where useful. Add one explicitly named homepage identity size. A rem is relative to the reader's configured root font size; clamp lets a role grow with available screen width between stated limits.

Replace every literal font-size declaration in component and page styles with the appropriate role. Apply the same scale to prose and controls, remove redundant responsive size overrides and move metadata to the body font. Keep layout, copy and semantic heading levels intact. Document this constraint in `ARCHITECTURE.md` so later work reuses the scale.
